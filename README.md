# Voshana Nissanka — Personal Website

This is my personal website, fully coded and designed by myself. It's built with Flask, HTML, CSS and Bootstrap, and serves as a central hub for everything I'm building and learning as a developer.

## What's Here

- **Landing Page** — a quick introduction to who I am and what I do
- **Projects** — a showcase of everything I've built, including live demos and GitHub links
- **Learning Log** — an interactive, constantly updated log of the courses, books, articles and topics I'm working through, backed by a SQLite database so I can keep adding to it over time
- **Contact** — a simple way to reach out directly via email

## Why I Built This

I wanted a space that isn't just a static portfolio, but something that grows alongside me — a live record of what I'm learning and building as I work toward becoming a stronger full stack developer.
